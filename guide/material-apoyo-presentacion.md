# Guion breve de apoyo para presentación WPC

Material de apoyo para explicar `pillars-capabilities.html` y `bondades.html` con lenguaje no técnico.

La idea es mantener un hilo continuo: primero se explica qué es WPC y qué piezas lo componen; después se traduce ese ecosistema a valor organizacional, impacto esperado y decisión recomendada.

## Apertura

- Hilo: WPC nace para evitar que cada solución digital empiece desde cero. La presentación debe abrir con una idea sencilla: cuando una organización repite proyectos, también repite decisiones; WPC convierte esas decisiones en una base común.
- Equivalencia: una plataforma de arranque ya preparada para construir nuevos productos.
- Palabras clave: base común, reutilización, orden, velocidad, conocimiento compartido.

## pillars-capabilities.html

### Diapositiva 1: WPC

- Hilo: Esta primera diapositiva presenta a WPC como el contenedor general. Antes de hablar de componentes, conviene dejar claro que no se trata de una aplicación aislada, sino de una base para construir varias soluciones con el mismo punto de partida.
- Equivalencia: una caja principal que reúne las piezas base para no armar cada proyecto desde cero.
- Palabras clave: contenedor, arquitectura modular, aceleración, base reutilizable.

### Diapositiva 2: Un contenedor. Cuatro capacidades.

- Hilo: Después de presentar el contenedor, se abre para mostrar sus cuatro capacidades. La idea es que WPC no resuelve todo con una sola pieza: separa responsabilidades para que el ecosistema sea más fácil de entender, repetir y mantener.
- Equivalencia: una organización con áreas claras que trabajan juntas.
- Palabras clave: ecosistema, capacidades, claridad, responsabilidades.

### Diapositiva 3: App Gateway

- Hilo: La primera capacidad es la entrada ordenada del sistema. App Gateway representa la parte que recibe, organiza y conecta las solicitudes con las reglas correctas, evitando que cada producto invente su propio camino.
- Equivalencia: la recepción de un edificio que orienta, valida y conecta con el área correcta.
- Palabras clave: entrada, reglas, base firme, orden, crecimiento controlado.

### Diapositiva 4: App Surface

- Hilo: Si App Gateway ordena la entrada, App Surface muestra la experiencia que recibe el usuario. Esta capacidad permite construir pantallas más consistentes y reutilizables, sumando interacción solo donde aporta valor.
- Equivalencia: la cara visible de la solución, diseñada para ser clara, útil y repetible.
- Palabras clave: experiencia, interfaz, consistencia, reutilización, rapidez.

### Diapositiva 5: Guía Versionada

- Hilo: Una vez explicadas las piezas que construyen la solución, aparece la pieza que conserva el conocimiento. La guía versionada evita que las decisiones se pierdan en conversaciones o dependan únicamente de personas específicas.
- Equivalencia: un manual vivo que explica qué existe, por qué existe y cómo debe usarse.
- Palabras clave: memoria, aprendizaje, trazabilidad, transferencia, continuidad.

### Diapositiva 6: Herramientas

- Hilo: Con la base, la experiencia y el conocimiento definidos, las herramientas permiten repetir el modelo con menos esfuerzo. Su valor está en convertir tareas frecuentes en acciones más rápidas, visibles y controladas.
- Equivalencia: instrumentos de trabajo que facilitan construir, revisar y mantener.
- Palabras clave: automatización, control, operación, consistencia, eficiencia.

### Diapositiva 7: WPC acelera con estructura.

- Hilo: El cierre de la primera parte une las cuatro capacidades. WPC acelera porque el orden ya está preparado: entrada, experiencia, conocimiento y herramientas trabajan como un mismo ecosistema.
- Equivalencia: empezar desde una base preparada en vez de una hoja en blanco.
- Palabras clave: velocidad con orden, estructura, reutilización, ecosistema.

## Transición hacia bondades.html

- Hilo: Hasta aquí se explicó qué contiene WPC. La segunda presentación responde por qué vale la pena adoptarlo: traduce las capacidades en beneficios para la organización.
- Equivalencia: pasar del mapa de piezas al caso de valor.
- Palabras clave: impacto, adopción, decisión, valor organizacional.

## bondades.html

### Diapositiva 1: Web Platform Core

- Hilo: La segunda parte retoma WPC desde el valor ejecutivo. Si antes se mostró el ecosistema, ahora se explica lo que produce: arranques más rápidos, equipos más alineados y un modelo corporativo común.
- Equivalencia: pasar de esfuerzos aislados a una capacidad compartida de la organización.
- Palabras clave: velocidad, estandarización corporativa, escalabilidad de equipos, activo reutilizable.

### Diapositiva 2: El costo de no estandarizar

- Hilo: Para justificar la adopción, primero se muestra el costo de no tener una base común. Cuando cada equipo resuelve lo mismo de formas distintas, se pierde tiempo, aumenta la dependencia de personas clave y los costos se vuelven menos predecibles.
- Equivalencia: dejar de pagar varias veces por resolver los mismos problemas.
- Palabras clave: costo repetido, variabilidad, riesgo, dependencia, enfoque en valor.

### Diapositiva 3: Un acelerador interno

- Hilo: Después del problema aparece la propuesta: WPC como acelerador interno. La organización puede iniciar productos sobre una base ya preparada y concentrar más energía en el objetivo de negocio.
- Equivalencia: una línea de salida preparada para distintos productos, áreas y equipos.
- Palabras clave: acelerador, base probada, menor fricción, reutilización, foco en valor.

### Diapositiva 4: Métricas que justifican la adopción

- Hilo: El valor debe poder medirse. Esta diapositiva aterriza la promesa en resultados esperados: menos tiempo de arranque, más capacidad efectiva, menos retrabajo y mayor continuidad.
- Equivalencia: medir WPC por capacidad de entrega, no solo por tecnología.
- Palabras clave: rapidez, capacidad, menos retrabajo, visibilidad, continuidad.

### Diapositiva 5: Decisión recomendada

- Hilo: El recorrido termina en la decisión: aprobar WPC como acelerador interno. No se está aprobando solo una herramienta, sino una forma común de construir soluciones con más velocidad, menos riesgo y mayor consistencia.
- Equivalencia: convertir experiencia acumulada en una capacidad reutilizable para la organización.
- Palabras clave: aprobación, acelerador interno, consistencia, menor riesgo, capacidad organizacional.

## Cierre sugerido

- Hilo: WPC existe para que cada nueva iniciativa no vuelva a empezar desde cero. Su valor está en convertir experiencia acumulada en una base común que ayuda a construir más rápido, con más orden y con menos dependencia de improvisación.
- Equivalencia: una forma repetible de transformar ideas de negocio en soluciones digitales.
- Palabras clave: construir mejor, repetir mejor, acelerar con estructura.
