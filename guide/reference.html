Contratos rápidos

Los contratos de esta tabla se desarrollan en Contratos HTML, JSON envelope y Headers de sesión.

Contrato Significado
success=true sin errores Éxito completo.
success=true con errores Respuesta parcial o degradada.
success=false Fallo bloqueante.
data-surface-page Root de page UI.
data-surface-fragment Root de fragment UI.
contracts.ts de una integración Firma TypeScript de payloads y data JSON que Surface ve desde una ruta Gateway.
composer robo -- surface:contract Genera bloques TypeScript en workspace/integrations/<feature>/contracts.ts desde Swagger/OpenAPI.
tools/HttpContractGenerator/Gateway Implementación del generador Gateway/PHP para contratos outbound.
tools/HttpContractGenerator/Surface Implementación del generador Surface dentro del generador común de contratos HTTP. Emite clases TypeScript para contracts.ts.
tools/HttpContractGenerator/Shared Lectura OpenAPI, utilidades de rutas, consola, reportes y nombres comunes compartidos por Gateway y Surface.
data-surface-page-status / data-surface-fragment-status Estado de montaje que Surface escribe para diagnosticar loading, mounted o error.
errors[] en envelope JSON Lista de errores visibles. Si success=true, indica respuesta parcial.
errorMeta Metadata técnica solo cuando el runtime permite exponer detalles de debug.
X-TAB-SESSION Identificador de pestaña enviado por surface.
X-REMAINING Tiempo restante de sesión emitido por gateway.
_flash.{tabId} Mensajes temporales de Gateway para el siguiente HTML SSR.

Headers HTTP

El detalle operativo vive en Headers de sesión y CSRF y tab session.

Header Dirección Uso
X-TAB-SESSION Surface → Gateway Identifica la pestaña activa para rutas autenticadas.
X-REMAINING Gateway → Surface Sincroniza el contador de expiración de sesión.
X-Correlation-Id Gateway → navegador/logs Permite rastrear una request entre UI, Gateway y upstreams.
Accept Navegador/Surface → Gateway Indica si se espera JSON, HTML completo o fragment HTML.
Content-Type Ambos lados Debe coincidir con JSON, form-data o HTML esperado.

Errores y status

Para semántica completa, se debe consultar Errores y resultados y Contratos de error HTTP.

ErrorKind Status típico Lectura rápida
BAD_REQUEST 400 Request mal formado o imposible.
VALIDATION 422 Input inválido para la intención de aplicación.
AUTHENTICATION_REQUIRED 401 Falta sesión válida.
FORBIDDEN 403 Sesión existe, pero la acción no está permitida.
NOT_FOUND 404 Recurso o ruta no encontrada.
CONFLICT 409 Choque con el estado actual de la aplicación.
DEPENDENCY_UNAVAILABLE 502 o 503 Falla upstream o de transporte externo.
UNEXPECTED 500 Error no esperado; debe registrarse y presentarse seguro.

Surface toolkit y fachadas

El catálogo con reglas de limpieza está en Toolkit, adapters y feedback.

Helper Uso Regla corta
toolkit/dom DOM, eventos, contenido y helpers de nodos. Debe usarse desde bindings o helpers UI.
workspace/integrations/<feature>/contracts.ts Tipos de request/response visibles para Surface. Lo importan api.ts y actions.ts; page.ts solo si necesita leer o anotar data.
workspace/integrations/<feature>/actions.ts Arma requests tipados desde valores semánticos y coordina feedback UI. Recibe valores de page.ts; no debe convertirse en service de dominio.
select2Adapter Selects enriquecidos. Destruir al desmontar.
dataTableAdapter Tablas con estado externo; la app consume la fachada de platform/infrastructure/adapters/datatable. No debe reemplazarse HTML sin destroy.
dateRangePickerAdapter Rangos de fecha. Limpiar el picker en unmount.
simpleModal Modales con HTML recibido; el remoto se resuelve desde la fachada de platform/infrastructure/feedback. Debe usarse withContentMount si trae fragments.
toastAdapter Toasts con HTML o fragment SSR desde la fachada de feedback. El contenido se desmonta al ocultarse.
swalAdapter Alertas, confirmaciones y formularios simples. No debe incluir negocio dentro del diálogo.

Outbound y connectors

El flujo completo está en API HTTP clients externos.

Pieza Uso
EndpointRequest Request hacia endpoint externo con DTO único.
EndpointListRequest Request hacia endpoint externo que devuelve lista.
CustomPayloadRequestInterface Payload especial cuando propiedades públicas no bastan.
ConnectorResult Resultado normalizado de integración para use cases.
ConnectorAliasRegistrar Alias por convención entre ports y connectors de `Infrastructure/Outbound/Connector`.
ServiceDefinitionFactory Lee services.json y variables API_* para definir base URI, bearer, timeout y TLS.
JsonServiceResponseMapper Valida si la respuesta externa es objeto o lista y falla si el shape no coincide.
ResponseHydrator Hidrata DTOs por constructor, tipos escalares, enums, fechas y objetos anidados.

Señales de diagnóstico

Estas señales no son negocio: son indicadores del runtime para ubicar dónde falló un flujo sin inferencias manuales.

Señal Dónde mirar Qué confirma
X-Correlation-Id Response del navegador y logs Gateway. Une request, response y llamadas upstream.
ResponseLogContext Responses observables de Gateway. Resume éxito, mensaje, cantidad de errores y origen.
RouteCache Producción o build de Gateway. Indica si la tabla de rutas quedó desactualizada.
data-surface-*-status DOM renderizado en el navegador. Confirma si page o fragment cargó, montó o falló.
Manifest Vite public/ui-assets/.vite/manifest.json. Confirma qué entry, CSS e imports se sirven.
