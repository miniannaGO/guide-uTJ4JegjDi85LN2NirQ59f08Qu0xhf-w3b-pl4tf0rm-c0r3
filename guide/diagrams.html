Diagramas del sistema

Mapas visuales para ubicar responsabilidades, recorridos y fronteras antes de profundizar en una explicación o en el código.

En esta página

Índice general

El visor presenta las fuentes Markdown/Mermaid disponibles sin convertirlas en una fuente de verdad independiente.

Los diagramas sirven como mapa visual para no perder el orden del sistema. Se deben usar para ubicar piezas, pero el detalle se debe validar en Gateway, Surface, Bridge o en el código real.

Mapas recomendados por tema

Estos accesos ayudan a elegir qué diagrama mirar según el tipo de problema. El visor carga los Markdown existentes; las páginas de guía explican el mismo flujo con ejemplos.

Bootstrap y DI

Diagrama de runtime/bootstrap/HTTP para ubicar providers, contenedor y ciclo inicial.

Observabilidad

Cruza DI, headers y telemetría para rastrear errores con X-CORRELATION-ID.

Content mount

Runtime pages/fragments junto con toolkit para entender modales, toasts y fragments remotos.

Errores HTTP

Combina JSON/session/assets contracts con errores para saber qué debe hacer Surface en cada status.

CSRF y tab session

Mapas de sesión y bridge para ver qué viaja por formulario, header y response.

Comandos Robo

Mapa de make:*, http:contract, surface:contract y los archivos que cada generador toca.
